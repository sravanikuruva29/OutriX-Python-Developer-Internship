# OutriX Python Developer Internship - 3 Completed Tasks

Selected tasks:
1. Task 1 - Basic Calculator with GUI
2. Task 3 - File Organizer Tool
3. Task 4 - Quiz Application with Score Tracker

All three are implemented using pure Python/basic standard-library modules.
No third-party packages are required.

## Requirements
- Python 3.x
- Tkinter (normally included with standard Python on Windows)
- Task 1 and Task 3 use Tkinter.
- Task 4 uses only Python standard-library modules.

## Run

### Task 1
python task1_calculator.py

### Task 3
python task3_file_organizer.py

### Task 4
python task4_quiz.py

## Task 1
Performs addition, subtraction, multiplication, and division through a GUI.
It validates numeric input and prevents division by zero.

## Task 3
Lets the user select a directory and automatically sorts files into folders
such as Images, Documents, PDFs, Videos, Audio, Archives, Spreadsheets,
Presentations, and Others. Existing filenames are not overwritten.

## Task 4
Runs a command-line Python quiz. Questions are stored in JSON, randomized,
answered interactively, and scored at the end. The question file is created
automatically on first run.

## Internship submission
The internship document says interns must select and complete at least three
Python Developer tasks and submit a video demo/link as part of the submission
process. Keep these projects as separate files for demonstration.
